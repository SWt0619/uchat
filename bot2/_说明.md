# AI 用户 #2「资料鱼」

与「大肥鱼」**完全独立**的一个 bot 实例（同一个 chatbot.mjs，靠 `--config` + `--base` 隔离）。

## 定位
- **只在被 @ 时触发**（`mentionRequiresAt: true` ⇒ 正文里出现名字**不算**，必须 `@资料鱼`）
- **详细作答**：分点/小标题、代码块、LaTeX 公式
- **贴参考链接**：优先官方文档/标准组织/权威百科

## 关键配置（`bot2/bot_config.json`）
| 键 | 值 | 说明 |
|---|---|---|
| `nickname` | `资料鱼` | 想改名就改这里（同时建议同步 persona 里的称呼） |
| `mentionRequiresAt` | `true` | **必须 @ 才触发** |
| `apiKeyLine` | `2` | **取 `..\dsapi.txt` 的第 2 行**作为 key（第 1 行是大肥鱼用的旧 key） |
| `maxTokens` | `2500` | 单次回答更长的上限 |
| `maxChunkChars` | `700` | 单条消息最长 700 字，超出会**按 Markdown 结构安全切片**（不在代码块/公式内部切断） |
| `maxPerMinute` / `globalMinGapMs` | 4 / 3000 | 频次限制（比大肥鱼宽松一些，因为回答更长） |
| `temperature` | `0.5` | 更低 ⇒ 更贴近事实 |

## 启动
- 随 Uchat 一起启动（已接入两个启动脚本 ✓）
- 也可单独双击 `start_bot2.bat` ✓；日志 `bot2\bot2.log` ✓
- 单实例锁在 `bot2\bot.lock`（与大肥鱼互不影响 ✓）

## 与「大肥鱼」的区别
| | 大肥鱼 | 资料鱼 |
|---|---|---|
| 触发 | `@` 或提到名字都行 | **必须 @** |
| 风格 | 简短、口语、傲娇 | 详细、分点、给来源 |
| 模型参数 | maxTokens 800、temp 1.0、关思考 | maxTokens 2500、temp 0.5、开思考 |
| key | `dsapi.txt` 第 1 行 | `dsapi.txt` 第 2 行 |
